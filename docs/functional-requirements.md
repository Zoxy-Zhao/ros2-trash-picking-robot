# 功能需求说明

## 1. 项目范围

本项目致力于开发一个完整的物联网（IoT）智能清洁解决方案。核心是一个能够自主执行垃圾拾取、分类和自我维护的智能机器人终端，并通过 MQTT 协议与远程控制端进行实时数据交互与控制，适用于办公室、图书馆等室内固定布局场景。

## 2. 智能终端功能

### 2.1 初始化与准备模块

| 需求 | 描述 | 优先级 |
|------|------|--------|
| 系统自启动 | 上电后自动加载 ROS2 系统、各功能节点及 YOLOv5 算法模型 | 高 |
| 自动上桶 | 接收"开始任务"指令后，通过升降机构自动从更换站抓取两个空垃圾桶并安放到位 | 高 |

### 2.2 巡航与导航模块

| 需求 | 描述 | 优先级 |
|------|------|--------|
| 预设路径巡航 | 按照远程控制端预设的路径点进行自主移动和巡航清扫 | 高 |
| 抵近目标 | 视觉系统发现垃圾后，自主导航至距垃圾适合机械臂作业的位置 | 高 |

### 2.3 视觉感知与处理模块

| 需求 | 描述 | 优先级 |
|------|------|--------|
| 大范围垃圾搜索 | 全局摄像头 + YOLOv5 实时扫描，检测视野内的潜在垃圾目标 | 高 |
| 垃圾精准识别与分类 | 局部摄像头 + YOLOv5 高精度识别，将垃圾分为"干垃圾"或"湿垃圾"两类 | 高 |
| 目标三维定位 | 通过相机标定和透视变换算法，将 2D 像素坐标精确转换为机械臂可用的 3D 世界坐标 | 高 |

### 2.4 抓取与分类执行模块

| 需求 | 描述 | 优先级 |
|------|------|--------|
| 机械臂精准抓取 | 根据视觉模块提供的 3D 坐标，通过逆运动学算法解算，精准地移动并夹取目标垃圾 | 高 |
| 自动分类投放 | 根据识别出的垃圾类型（干/湿），将其准确投放到对应的机载垃圾桶中 | 高 |

### 2.5 自我维护模块

| 需求 | 描述 | 优先级 |
|------|------|--------|
| 满溢状态检测 | 通过传感器或视觉算法判断机载垃圾桶是否已满 | 中 |
| 自动换桶 | 检测到垃圾桶已满后，自动暂停清扫任务，导航至更换站，并执行全自动的换桶流程（卸下满桶装载空桶） | 中 |

### 2.6 物联网通信与远程管控模块

| 需求 | 描述 | 优先级 |
|------|------|--------|
| MQTT 连接 | 启动后自动连接到指定的 MQTT 服务器 | 高 |
| 状态数据发布 | 以固定频率向 MQTT 服务器发布状态数据（电量、垃圾数、桶状态、当前任务等） | 高 |
| 远程状态显示 | 远程控制端 GUI 实时订阅并展示从机器人接收到的所有状态数据 | 高 |
| 远程指令下达 | 远程控制端提供操作接口，允许用户下达控制指令（启动/停止任务、选择清扫模式、返回更换站等） | 高 |
| 指令接收与执行 | 机器人终端订阅控制指令主题，并准确执行相应的操作 | 高 |

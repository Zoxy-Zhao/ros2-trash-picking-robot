# 系统设计与坐标约定

## 系统分工

Jetson 上运行图像采集、目标检测、连续帧确认、平面定位、逆运动学与轨迹生成；STM32 接收 UART 指令并驱动执行机构。Web 通过 MQTT 交互，仓库尚未包含完整机器人端 MQTT 桥接。软件提供六轴验证入口及四轴兼容接口。

## 六轴构型与默认尺寸

默认软件示例配置如下，长度单位为 cm，需按实际机构替换：

| 参数 | 配置值 |
|---|---|
| 基座高度 | 15.0 |
| 上臂长度 | 10.4 |
| 前臂长度 | 9.1 |
| 工具长度 | 5.0 |

`robot.yaml` 的 `link_dimensions_cm` 与求解器 `Geometry` 使用同一顺序。

`six_axis.py` 的构型为 Z-Y-Y 定位臂及相交的 Z-Y-Z 球形腕。长度单位 cm，关节与 RPY 接口单位度。基座 Z 向上；正 Y 轴旋转将正 X 方向连杆转向负 Z。

定义 `Rz`、`Ry` 为右手主动旋转：

```text
R03 = Rz(q1) Ry(q2) Ry(q3)
R06 = R03 Rz(q4) Ry(q5) Rz(q6)
p_w = [0, 0, h] + Rz(q1) Ry(q2) [L2, 0, 0]
                    + R03 [L3, 0, 0]
p_tcp = p_w + R06 [0, 0, tool]
```

输入姿态 `R = Rz(yaw) Ry(pitch) Rx(roll)`。IK 首先从 TCP 减去工具偏置得到腕心，枚举基座与肘部方向，利用余弦定理求解前三关节，再对 `R03.T R` 做 Z-Y-Z 分解。每个候选解必须满足限位并通过 FK 复核。以实际关节角差选取邻近解，避免跨越硬限位的模 360 度捷径。

这不是任意六轴机械臂的通用求解器。实际结构若不符合球形腕和轴线约定，需要更换模型。奇异构型保留种子角并尝试限位端点，不宣称穷举所有奇异连续解。

## 视觉坐标

`perspective.py` 与离线演示共用 `plane_geometry.py`，从标定矩阵将图像点映射到标定平面，输出 X/Y。矩阵必须为有限、非退化的 3×3 单应矩阵；抓取 Z 来自 `grasp_z_cm`，不从单目图像重建任意深度。相机安装、分辨率或抓取平面变化后应重新标定。

## 抓取状态流程

```text
idle → pausing → localizing → grasping → resuming → idle
                         失败或未知执行状态 → fault
```

连续新帧中目标类别和位置满足阈值才触发流程。空帧、低置信度、类别变化或目标位置跳变重置确认计数。相同或倒退的非零时间戳不计入连续帧数量；无有效时间戳的输入也不触发确认。

执行前求解全部路径点：目标上方、目标、抬升点、对应桶上方、投放点、桶上方、待机姿态。未知类别拒绝投放，类别到干湿桶的映射在配置文件中定义。

六轴 ROS 服务与离线演示共用 `grasp_plan.py`。抬升与桶上方高度统一为 max(目标高度, 桶高度)+接近高度；夹爪在抓取/投放后独立控制。

路径为关节空间插值，路径点 IK 成功不代表连杆或搬运路径无碰撞。当前没有碰撞模型、力反馈或关节到位传感器。`theta_now` 只是指令位置估计。

## 轨迹

归一化时间 `s` 使用五次曲线 `10s³ - 15s⁴ + 6s⁵`，各关节同步起止。时长根据最大关节位移、速度和加速度上限推导。输出离散整数角度给固件，因此连续数学轨迹的平滑性不等同于舵机实际运动精度。

## 故障处理

不可达目标在动作前拒绝；UART 服务超时、写入失败等锁定故障，避免未知位置下继续自动抓取。UART 服务返回发送状态，不提供关节到位反馈。六轴固件默认未启用，必须校准并设置 `ARM6_ENABLED` 后使用。

# 系统设计说明

## 1. 设计目标

- **全流程自动化**：从任务准备（自动上桶）、自主执行（巡航、识别、抓取、分类）到自我维护（自动换桶）的闭环工作流，最大限度减少人工干预
- **云端一体化**：构建稳定、实时的"端-管-云"物联网系统，实现远程监控、数据分析和指令下发
- **高精度与高可靠性**：融合 AI 视觉算法与经典机器人控制算法，确保垃圾识别的准确性和机械臂动作的可靠性
- **模块化设计**：基于 ROS2 框架，实现各功能模块的低耦合，便于维护和扩展

## 2. 系统整体架构

本项目采用标准的三层物联网（IoT）架构：

1. **机器人终端（终端执行单元）**：感知与执行层，负责在物理世界中完成所有清洁任务，并作为数据采集的源头
2. **MQTT 服务器（消息中枢）**：通信核心，承担消息代理（Broker）角色，负责机器人终端与 Web 控制中心之间所有数据的可靠中继与分发
3. **净境控制中心（Web 客户端）**：交互与管理层，提供可视化 Web 界面，实现机器人状态的实时监控和远程任务管理

## 3. 机器人终端设计

### 3.1 硬件设计

| 模块 | 组件选型 | 设计说明 |
|------|---------|---------|
| 机身结构 | 亚克力板 + 3D 打印件 | 轻量化且坚固，自主 3D 建模（SolidWorks），实现各电子元器件和执行机构的高度集成与定制化布局 |
| 主控核心 | 上位机：NVIDIA Jetson Orin NX / 下位机：STM32F103ZET6 | 主从式计算架构。Jetson 运行 Ubuntu 和 ROS2，负责 AI 视觉识别、路径规划等高算力任务；STM32 负责电机 PID 闭环控制、传感器数据读取等高实时性底层任务。两者通过 UART 串口进行指令和数据交互 |
| 视觉模块 | 全局摄像头 + 局部摄像头 | 双目协同策略。全局摄像头用于大范围巡航时的目标搜索；局部摄像头用于抵近目标后的二次精准识别、分类及三维定位 |
| 执行机构 | 多自由度机械臂、升降机构、差速驱动底盘 | 多机构联动。机械臂负责垃圾的精准抓取与投放；原创的升降机构与夹爪协同，实现全自动的上桶与换桶操作；底盘提供稳定可靠的移动能力 |

### 3.2 软件设计

| 模块 | 核心技术/算法 | 设计说明 |
|------|------------|---------|
| 操作系统 | ROS2 | 作为整个机器人软件系统的骨架，利用节点（Node）和话题（Topic）机制，实现视觉、导航、控制等所有功能模块的解耦和异步通信，保证系统的高稳定性和高效率 |
| 视觉系统 | YOLOv5 + 视觉标定（透视变换） | 依赖在自定义数据集上训练的 YOLOv5 模型进行目标检测与分类。通过精准的相机标定和透视变换算法，将图像中的 2D 像素坐标转换为机器人世界坐标系下的 3D 坐标，为机械臂抓取提供精确的目标点 |
| 底盘控制 | PID 算法 | 对底盘驱动电机采用经典的 PID 闭环控制算法，通过实时读取电机编码器数据，精确控制机器人的速度和姿态，确保其在执行预设路径时启停平稳、定位精准 |

### 3.3 ROS2 节点架构

```
robot_launch/start.py (启动入口)
    │
    ├── camera_publisher      ← robot_vision: CSI 摄像头图像采集与发布
    ├── yolo_detection        ← robot_vision: YOLOv5 实时目标检测（GPU 加速）
    ├── perspective_service   ← robot_vision: 透视变换，2D 像素→3D 世界坐标
    ├── main_node + detection_subscriber ← robot_core: 检测结果融合与决策
    ├── arm_control           ← robot_arm: 逆运动学解算 + 关节插值运动
    └── serial_send           ← robot_serial: UART 指令发送至 STM32
```

**数据流**：摄像头 → YOLO 检测 → 目标筛选（连续10帧高置信度确认）→ 透视变换坐标转换 → 逆运动学解算 → 关节平滑插值 → UART 发送舵机指令

## 4. 物联网通信与 Web 控制中心

### 4.1 通信协议与消息中枢

- **核心协议**：MQTT，轻量、高效、支持发布/订阅模式，适用于物联网场景
- **消息中枢**：EMQX（Docker 部署），高性能 MQTT Broker

### 4.2 Web 控制中心功能

| 功能模块 | 说明 |
|---------|------|
| 状态监控中心 | 电源系统（电量/运行状态）、垃圾收集（干/湿垃圾桶状态）、运行状态（工作模式/运行时长）、网络状态 |
| 智能控制中心 | 自动模式（预设清扫路径）、手动模式（虚拟摇杆遥控）、高级控制（换桶/巡航/紧急停止）|
| 系统信息中心 | 设备信息（处理器/内存/存储）、操作日志（实时记录所有关键操作） |

### 4.3 数据流设计

1. **上行数据流**：机器人终端周期性地将状态（电量、桶状态等）打包成 JSON，发布到 MQTT 服务器
2. **下行数据流**：用户在 Web 控制中心的操作生成 JSON 控制指令，发布到 MQTT 服务器
3. **数据分发**：MQTT 服务器根据发布/订阅关系，将上行数据实时推送给 Web 客户端，同时将下行指令实时推送给机器人终端

## 5. 核心算法细节

### 5.1 逆运动学（IK）

4轴机械臂参数（单位 cm）：L1=15, L2=10.4, L3=9.1, L4=18.4

解算流程：
1. 遍历末端执行器角度（100°→0°，步长10°）
2. 对每个角度，将目标点旋转修正后计算关节角度
3. 使用余弦定理求解肘部角度 θ2、θ3
4. 通过正运动学验证，计算腕关节角度 θ4
5. 返回第一组有效解

### 5.2 目标确认机制

采用连续帧确认策略，防止误触发：
- 目标置信度 > 70% 且位置合法
- 连续超过 10 帧满足条件才触发抓取
- 抓取过程中暂停 YOLO 检测，完成后重新开启

### 5.3 关节平滑插值

机械臂运动采用等步长插值：
- 每个关节以固定角度步长（5°/步）同步运动
- 每步间隔 100ms，通过 UART 发送舵机指令
- 确保运动平滑、无冲击

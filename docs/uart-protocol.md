# UART 串口通信协议

Jetson 默认 `/dev/ttyTHS1`，115200 bps、8N1。每条 ASCII 指令以 CRLF 结束；上位机发送节点统一添加终止符，正文最多 62 字节。

## 机械臂

| 指令 | 参数 | 行为 |
|---|---|---|
| `ARM q1 q2 q3 q4` | 4 个角度，度 | 原四轴样机映射 |
| `ARM6 q1 q2 q3 q4 q5 q6` | 6 个角度，度 | 六轴独立协议，需启用固件配置 |
| `CLAW 0` / `CLAW 1` | 张开 / 闭合 | 使用 PCA9685 通道 5 |
| `CHANGE direction` | 0 / 1 / 2 | 原换桶机构动作，非自主导航命令 |

六轴关节对应通道 0、1、2、3、4、6。`arm6_config.h` 配置零位、方向和行程，默认 `ARM6_ENABLED=0`。启用前校准，并让 ROS 关节限位落在固件校准后的可执行范围内。固件拒绝参数数量不匹配或映射越界的六轴帧，绝不把六轴帧截成四轴执行。

## 底盘

保留 `GO speed`、`BACK speed`、`LEFT angle`、`RIGHT angle`、`STOP` 等原型命令。`STOP` 只作用于底盘，**不提供机械臂急停语义**。

## 传输行为

DMA 接收缓冲区、队列元素与解析长度统一；串口 1/2 使用独立缓冲。按行处理分包与连包，过长行丢弃到下一终止符。非法数字（含 NaN/Inf）、多余参数使整条指令无效，命令词统一转为大写。

`send_uart_message.success` 只表示主机串口写入完成。当前没有 MCU ACK、序列号重传或关节反馈，因此不能据此声称执行到位。接收队列满时仍可能丢帧，硬件闭环交付需要补充确认协议和反馈。

```text
ARM6 0 -30 60 0 30 0\r\n

CLAW 1\r\n

```

不要向仍接着四轴样机的板卡开启六轴输出。原四轴代码与六轴参考构型的连杆及零位约定不同。
